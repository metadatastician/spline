= Spline readiness — 2026-09-05

*Release decision: not production-beta approved.* Spline remains a deliberately
thin alignment repository under ADR 0005.

The alignment ledger records Burble live encoding (a), a Gossamer decoder (b),
and Groove's CI conformance check (c). A fresh local run can reproduce (c);
it cannot renew the historical consumer results or close the live-pairing gate (d).

The former test templates did not exercise a Spline executable. The aspect
entry point now runs the authoritative alignment check with an explicit Groove
checkout. The e2e entry point fails with an actionable unmet-gate message until
an actual pairing runner exists. Neither is evidence of a deployed wire service.

Before beta: satisfy link:BETA-ACCEPTANCE.adoc[the live capture and stability
contract], then record home-context use and six diverse external targets under
the existing CRG policy. An owner must choose the target environment and collect
external feedback; local test variants do not count as external targets.

Machine-readable descriptions live under `.machine_readable/descriptiles/`.
See link:PROOF-STATUS.adoc[proof status] for the mathematical boundary.
