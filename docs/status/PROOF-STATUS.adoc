= Spline proof status — 2026-09-05

== What has been checked

Groove's authoritative Bebop alignment checker accepts its eleven recorded
variants, and its three falsification self-checks pass. Reproduce from this repo:

[source,bash]
----
bash tests/check_alignment.sh /absolute/path/to/groove-checkout
----

The script reports the checkout and commit used. This is executable finite
conformance evidence for ADR 0005 criterion (c), not a universal codec proof.

== What remains open

* A newly captured live Burble–Gossamer typed-token pairing: criterion (d).
* Universal encoder/decoder correspondence over the supported domain.
* Noninterference of posture/rank with wire bytes across actual endpoints.
* Proof-to-runtime refinement and transport fault assumptions.

There is no meaningful percentage obtained by counting template theorem names.
No Spline ABI/FFI implementation is claimed; such obligations become applicable
only if an approved implementation introduces that boundary.
