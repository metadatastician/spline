= Alignment: the VoiceSignal plane
:revdate: 2026-09-07

Spline owns the *alignment* between the joinery's data-plane peers — never a
copied schema (ADR-0003). This document is the human half of the VoiceSignal
alignment; the machine-readable half lives in groove's registry (SSOT
pattern) and is CI-enforced there.

== The mapping

[cols="1,3"]
|===
| Schema (owner)
| `metadatastician/burble` `server/priv/schemas/voice_signal.bop` — burble
  owns the schema and the generator (`mix bebop.generate`); *burble's
  generator output, not the Bebop spec, is what is deployed*.

| Machine-readable alignment
| `metadatastician/groove` `registry/bebop-voice-signal-alignment.json` —
  tag→variant mapping, per-variant field layouts, wire facts, cross-plane
  `LeaveReason` value alignment.

| Conformance test (criterion (c))
| groove CI, `spec-consistency` job → `scripts/check-bebop-alignment.mjs`:
  every recorded frame's tag must map to its claimed variant, the declared
  layout must consume the frame exactly, all 11 variants must be exercised.

| Recorded frames
| Produced by burble's actual codecs; vendored (with provenance headers) at
  groove `spec/conformance/bebop/voice_signal_frames.hex` and gossamer
  `src/interface/ffi/src/testdata/voice_signal_frames.hex` — the same bytes
  validate both the alignment and the second consumer.

| Second consumer (criterion (b))
| gossamer `src/interface/ffi/src/bebop_voice_signal.zig` — pure-Zig strict
  decoder for all 11 variants, interop-tested against the recorded frames
  under `zig build test`.
|===

== Cross-plane obligations

* `voice_signal.LeaveReason` MUST stay value-aligned with
  `room_event.LeaveReason` (burble owner ruling A3, 2026-08-04): Voluntary=0,
  Kicked=1, Banned=2, Timeout=3, ServerShutdown=4. The room-event plane
  reports the departure the voice-signal plane initiates.
* Decoder strictness is part of the alignment since 2026-08-04 (burble ruling
  A4): truncated or malformed input is REJECTED by both consumers — a frame
  declaring more bytes than it carries must never decode to defaulted values.

== Local consumer capture — 2026-09-07 (uncommitted worktrees)

The scoped Gossamer/Burble adapter now exercises a real signaling capability:
the native ReleaseSafe Gossamer library sends full VoiceSignal SDP/ICE through
Burble's authenticated, room-and-peer-bound HTTP voice lease; a real WebSocket
peer receives the SDP as a Bebop SdpPayload wrapper and replies through the
ordinary signaling channel. Gossamer's production decoder parses the returned
VoiceSignal answer and ICE frames. This is not an echo endpoint or just a codec
fixture test. Burble's integration gate builds both native drivers and runs the
actual HTTP/WebSocket Endpoint (`server/integration/check_gossamer_pairing.sh`).

The capture repeats the same protocol fixtures under soft and hard leases and
asserts equality of the observed signaling payloads and returned native frames.
That is concrete data-plane evidence for (d), *not* a proof that negotiation,
credentials, timing, channel reference fields, or whole transcripts are equal.
No posture argument enters the payload codec. There is no proof-to-binary
refinement or general distributed noninterference theorem in this capture.

Criterion (a) also needs qualification: legacy WebSocket delivery normalizes
SDP back to JSON. Capable clients now explicitly request `wire_format: bebop`
at channel join and receive actual encoded SDP on the socket. A default flag
alone never established that external wire path.

Promotion remains OPEN. The host-loop maintenance hook is implemented and
exercised by the native driver, but not integrated into the desktop shell.
Fixtures demonstrate signaling, not negotiated media, NAT/TURN connectivity,
audio, or external field trials. The original Cleave O-6/O-7 and refinement
obligations are unchanged. No Spline implementation directory is introduced.
